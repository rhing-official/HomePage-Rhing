# /server

呼び出されたら、以下を順に行う。この一連の操作はローカル環境内で完結し、外部への影響が無いため、確認なしで実行してよい。

## 1. 依存関係の確認

- `node_modules/`が存在しない場合は`npm install`を実行する。
- 存在する場合でも`package-lock.json`が`node_modules/`より新しく更新されている等、明らかに不整合が疑われる場合はユーザーに`npm install`し直すか確認する。

## 2. 既存プロセスの確認

- このプロジェクトの`next dev`が既に起動していないか確認する(例: `lsof -i :3000 -i :3001`、または`ps aux | grep "next dev"`)。
- 既に起動中であれば、二重起動せずそのURLをそのまま案内して終了する。

## 3. 開発サーバーを起動

- リポジトリルートで`npm run dev`をバックグラウンド実行する(Bashツールの`run_in_background: true`を使う)。
- 起動直後のログを数秒〜十数秒待って確認し、"Ready"等の起動完了メッセージと実際に待ち受けているポート番号を把握する(3000番が使用中の場合はNext.jsが自動的に3001番等へずらすことがあるため、ログに出た実際のポートを使う)。
- 起動失敗(エラーで終了、ポート競合が解決できない等)の場合はログの内容をそのままユーザーに提示する。

## 4. 結果報告

- 実際に使われたURL(例: `http://localhost:3000`)をユーザーに伝える。
- 停止したい場合はバックグラウンドタスクを止めればよい旨を一言添える。
