# 意匠の`pack.json`: メニューチップの画像（DaiDaiアプリ側の担当へ）

2026-11-27。HomePageの意匠の作成画面（`/daidai-yokocho/creator/themes/create`）が、次の項目を書き出す。アプリ側の描画と、サーバー側（DaiDaiの`submitThemePack`など）の検査は、まだ対応していない。

## 形式

`formatVersion`は1のまま。`images`に、任意の項目`menuChip`を足した。

```json
"images": { "background": "background.png", "menuChip": "menu-chip.png" }
```

- `images`は、部品名からファイル名への対応表。今回の部品は`menuChip`だけ。他の部品は、同じ形で足す。
- 古いアプリは、未知の項目を無視して読める。
- ファイル名の規則は、`background`と同じ（英数字・アンダースコア・ハイフンと拡張子。ディレクトリ・`..`・URLは不可）。

## 制限（HomePage側の検査）

- PNGだけ。透過できる。
- 各辺512px以下、1枚512KB以下、1枚だけ。
- 背景画像と同じファイルは指定できない。
- 状態ごとの画像（選択中と非選択など）は、今回は持たない。将来の拡張。

## 対応が要ること

- アプリ: `ThemePackParser`で`images.menuChip`を読み、メニューチップの見た目に使う。
- サーバー: `submitThemePack`の検査が、背景画像以外のPNGを許すか、確認する。許さない場合は、投稿が拒否される。
- 定数は、HomePageの`src/lib/themePack/spec.ts`の`THEME_PACK_LIMITS.menuChipMaxSide`・`menuChipMaxBytes`。
