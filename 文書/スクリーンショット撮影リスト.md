# DaiDaiページ スクリーンショット撮影リスト

作成: 2026-11-18。対象は `src/app/services/daidai/AudienceContent.tsx` の `ScreenshotPlaceholder` 9枚（機能紹介4枚＋アプリの画面5枚）。撮影はユーザーが行う。

## 共通
- 保存先: `public/screenshots/daidai/`（無ければ作る）。形式は WebP（品質80前後）。PNGで撮ってから変換してよい。
- 他人の個人情報（名前・アイコン・メッセージ本文・Rhing Seed）が写らないよう、テスト用アカウントで撮る。
- 通知バー・ブラウザのタブ・個人のブックマークが写り込まないようにする（ブラウザは全画面か、画面だけを切り抜く）。
- ライトモード・既定のUIスタイル（フラット）・既定のフォントで揃える。`01`の「見た目の切り替え」だけは、スタイルごとに撮る。
- 文字が読める大きさで撮る。縮小して載せるため、撮影時は推奨サイズの2倍まで大きくてもよい。

## OGP画像（別枠）
- 用途: `/services/daidai` を共有したときの画像。
- 保存先: `public/og/daidai.png`、1200×630、PNG。
- 置いたら、`src/app/services/daidai/page.tsx`の`metadata.openGraph.images`に `[{ url: "https://rhing.jp/og/daidai.png", width: 1200, height: 630, alt: "DaiDai" }]` を足し、`twitter.card`を`"summary_large_image"`・`twitter.images`に同じURLを入れる。daidai横丁にも使う場合は、`public/og/daidai-yokocho.png`を同様に用意する。

## 画像が `public/` に置かれたあとの差し替え手順
1. `AudienceContent.tsx`の先頭に `import Image from "next/image";` を足す。
2. `ScreenshotPlaceholder`の呼び出しを、`ScreenshotPlaceholder.tsx`を拡張するか、直接`next/image`に差し替える。枠は維持する。
   - 横長: `<div className="relative aspect-[16/9] w-full overflow-hidden rounded-m3-lg border border-gray-200"><Image src="/screenshots/daidai/home-desktop.webp" alt="（説明文）" fill sizes="(min-width: 1024px) 50vw, 100vw" className="object-cover" /></div>`
   - 縦長: `aspect-[9/16]`、`sizes="(min-width: 1024px) 20vw, 50vw"`。
   - `alt`は、`label`の説明（「ホーム画面…」）から`[SCREENSHOT: …]`の枠を外した文にする。装飾でない画像なので、空にしない。
   - 先頭に近い画像（機能紹介の1枚目）だけ、`priority`を付けてよい。他には付けない。
3. もっとも簡単なのは、`ScreenshotPlaceholder`に`src?: string`を足し、`src`があれば`next/image`、無ければ従来の破線の枠を出す形。画像が来た枚数だけ、呼び出しに`src`を足していける（9枚が揃うまで、混在でよい）。
4. `npm run build`で、`next/image`の警告・`alt`の指摘が無いことを確認する。画像が大きすぎる場合は、1600px幅に縮小する（`next/image`が配信時に最適化する）。
5. 差し替えた枚数と、残りのプレースホルダを、`文書/日記.md`のTODOに記録する。
