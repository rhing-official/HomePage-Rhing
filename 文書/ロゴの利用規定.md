# フッター「メディア」のロゴの利用規定

確認日: 2026-11-18。公式ページに書いてあることだけを記録する。法的助言ではない。
2026-11-18: ユーザーの判断で、フッターのアイコンは全て廃止した（テキストのみ）。以下は、将来ロゴを使う場合の調査記録。`public/brand/`のGitHubのロゴも削除済み。
目的: フッターの自分たちの公式アカウントへのリンクに、各サービスのロゴ（小さなアイコン、単色）を使ってよいか。

| サービス | 判定 | 根拠 | 状態 |
|---|---|---|---|
| GitHub | 使ってよい | https://brand.github.com/foundations/logo : 「Social button: Use the Invertocat logo as a social button to link to your GitHub profile or project.」。白・黒の使用可、変形・色の変更は禁止、自社ロゴより目立たせない、事業のロゴとして使わない。ZIP: https://brand.github.com/GitHub_Logos.zip | `public/brand/github-invertocat-black.svg`（ZIP内`GitHub Logos/SVG/GitHub_Invertocat_Black.svg`をそのままコピー）。フッターに設定済み |
| Discord | 条件付きで可。素材の形が合わない | https://discord.com/branding : 「Feel free to use our logo in color, black or white.」「Use the Discord Marks to inform people that you are a Discord user and/or that you have a Discord server」。編集・変形・色変え・再構成は禁止。公式の配布は、ロゴ＋文字の横長（219×32）のみ（シンボルだけの素材は、読めた範囲に無い。「View Brand Kit」は未読） | 横長のロゴは、アイコンとして切り出せない（切り出しは改変にあたる）。ユーザーの判断待ち。仮のアイコンは汎用の吹き出し |
| Instagram | 未確認 | https://www.meta.com/brand/resources/instagram/instagram-brand/ : 「Anyone using Instagram's assets should only use the logos and screenshots found on our Brand Resource Center site」。色・サイズ・リンク用途の詳細は、別ページ（https://www.facebook.com/brand/resources/instagram/icons）にあるが未読。素材のZIPは同意の画面の先で、SVGの有無は未確認 | 保留。仮のアイコンはカメラ |
| X | 未確認 | https://brand.x.com は402、https://about.x.com は403で、読めなかった | 保留。仮のアイコンは@ |
| Qiita | 営利は事前連絡が必要 | https://help.qiita.com/ja/articles/others-brand-guideline : 「非営利目的でのブランドアセットのご利用は自由に行っていただけます。」「営利目的でのブランドアセット利用をご希望の場合は、事前にQiita株式会社までご連絡ください。」。配布はZIP（PNG・Illustrator）で、SVGは無い。単色の可否は明記なし | 保留。個人事業のサイトが営利にあたるかを、サポートフォーム https://support.qiita.com/hc/ja/requests/new で問い合わせる必要がある |
| Zenn | 不明確 | https://zenn.dev/mediakit : 「メディア等でご紹介いただく際にご自由にお使いください。」「素材を変形しないでください」「原則として使用ロゴはフルカラー版をご使用ください」。グレースケールは、フルカラー版を使えない場合に限る。自分のアカウントへのリンク用途の記載は無い。配布はZIP（https://static.zenn.studio/images/mediakit/zenn-logo.zip） | 保留。フルカラーなら使える可能性がある |
| note | 未確認 | ロゴ素材のページ https://www.help-note.com/hc/ja/articles/360000235582 が403で読めなかった | 保留。仮のアイコンはペン |

## 注意
- ロゴは、各社の商標。変形・色変え・角丸・切り抜きをしない。
- GitHubの「事業のロゴとして使わない」「自社名・自社ロゴより目立たせない」を守る（フッターの小さなリンクのアイコンとして使う）。
- 取得した素材は、`/tmp/brand-dl/`（リポジトリ外）に展開した。リポジトリに入れたのは、中身を確認したSVG（スクリプト・外部参照なし）1つだけ。
