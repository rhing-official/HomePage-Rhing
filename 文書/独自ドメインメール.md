# 独自ドメインメール（@rhing.jp）の受信・送信

`info@rhing.jp` などの独自ドメインのアドレスを、**無料**で受信・送信できるようにするための方針と手順。作成のきっかけは、NOWPayments（ビットコイン寄付の決済サービス）の登録で、gmail.comなどのフリーメールが「Invalid corporate email」として弾かれたこと（法人格は不要で、独自ドメインのアドレスが必要なだけ）。

## 構成（無料）

| 役割 | サービス | 内容 |
|---|---|---|
| 受信 | ImprovMX（無料プラン） | `info@rhing.jp` 宛てのメールを、転送先（Proton Mail）へ転送する。1ドメイン・25エイリアスまで |
| 送信 | Brevo（無料プラン）＋ Gmail の「別のアドレスから送信」 | Gmailの送信元に `info@rhing.jp` を追加し、Brevo の SMTP 経由で送る。1日300通まで |

- 転送先: `rhing.official@proton.me`（受信用。Protonの無料アカウント）
- 送信に使う受信箱: Gmail（`rhing.official@gmail.com`）。Proton Mail の無料プランでは独自ドメインでの送信ができないため、送信だけ Gmail から行う
- Gmail の SMTP を直接使うと、メールが gmail.com 名義で署名され（DKIM）、独自ドメインと一致せず迷惑メール判定されやすい。そのため、`rhing.jp` で署名できる Brevo を通す

## 現状（2026-10-17時点）

- ドメイン `rhing.jp` の管理: Xserver Domain（ネームサーバーは `ns1〜3.xdomain.ne.jp`）。**「ネームサーバー設定」は変更しない**（サイト表示に影響する）。DNSの編集は左メニューの「DNSレコード設定」で行う
- 既存のDNS: 所有確認用のTXT（`google-site-verification=…`）あり、MXなし。SPF（`v=spf1 …`）のTXTはまだ無い
- ImprovMX: ドメイン `rhing.jp` を追加済み。2026-10-17にDNS（MX 2件とSPFのTXT）を追加し、ステータスが緑になった。エイリアスは `info` のみ（転送先 `rhing.official@proton.me`）。送信（B）は未設定

## A. 受信の設定（先にやる）

- [x] 1. Protonの無料アカウント `rhing.official@proton.me` を用意する
- [x] 2. ImprovMX でエイリアスを整える
  - キャッチオールの `*` は迷惑メールをすべて受けるため、削除する
  - `info` を追加し、転送先を `rhing.official@proton.me` にする
  - 転送先に確認メールが届く場合は、Proton で承認する
- [x] 3. ImprovMX の画面（ドメイン名または「Setup」）に表示されるDNSの値を確認する。通常は次の3件（**ImprovMXの画面の値を優先**）

  | 種類 | ホスト名 | 値 | 優先度 |
  |---|---|---|---|
  | MX | `rhing.jp`（ルート） | `mx1.improvmx.com` | 10 |
  | MX | `rhing.jp`（ルート） | `mx2.improvmx.com` | 20 |
  | TXT（SPF） | `rhing.jp`（ルート） | `v=spf1 include:spf.improvmx.com ~all` | — |

- [x] 4. Xserver Domain の「DNSレコード設定」に、上の3件を**追加**する
  - 既存のレコード（GoogleのTXT、サイト表示用のA/CNAME等）は消さない
  - ホスト名・値の末尾の「.」の要否は、画面の入力例に従う
- [x] 5. 反映を確認する（数分〜数時間かかる）
  ```bash
  dig +short MX rhing.jp
  dig +short TXT rhing.jp
  ```
  ImprovMX の「Setup」が緑になることも確認する
- [x] 6. 別のアドレスから `info@rhing.jp` にテストメールを送り、Proton に届くか確認する（迷惑メールフォルダも見る）
- [ ] 7. NOWPayments の登録メールアドレスに `info@rhing.jp` を使う

> 2026-10-17: 手順1〜6を完了（ImprovMXが緑になり、`rhing.official@gmail.com`から`info@rhing.jp`へ送ったテストメールがProtonに届くことを確認）。手順7（NOWPaymentsの登録）は未実施。

## B. 送信の設定（後でやる）

送信が必要になった時点で行う。NOWPayments の登録だけなら受信（A）で足りる。

- [ ] 1. Brevo の無料アカウントを作り、送信ドメインとして `rhing.jp` を追加・認証する
- [ ] 2. Brevo が指示する**SPFとDKIMのDNSレコード**を Xserver Domain の「DNSレコード設定」に追加する
  - **SPFは1つのTXTにまとめる。** 同じ名前に `v=spf1` で始まるTXTを2本作ると、どちらも無効になる。ImprovMX用（`include:spf.improvmx.com`）とBrevo用の`include:`を、1つの`v=spf1 … ~all`に並べる
  - DKIM（CNAMEまたはTXT）は、Brevoの画面の値をそのまま追加する
- [ ] 3. Brevo の SMTP 情報（サーバー名、ポート、ログインID、SMTPキー）を取得する。**SMTPキーは公開しない（リポジトリやチャットに貼らない）**
- [ ] 4. Gmail の設定 →「アカウントとインポート」→「他のメールアドレスを追加」で `info@rhing.jp` を追加し、「SMTPサーバー経由で送信」に Brevo の SMTP 情報を入力する
- [ ] 5. 確認コードのメールが `info@rhing.jp` 宛てに送られるので、受信（A）経由で受け取って承認する
- [ ] 6. テスト送信し、受信側でSPF/DKIMが通っているか、迷惑メールに入らないかを確認する

## 注意

- ImprovMX の無料プランは転送（受信）のみ。SMTPによる送信はPremium（月$9）なので使わない
- 将来、別のメールサービスへ移るときは、MXレコードを置き換える（複数のサービスのMXを混在させない）
- 送信を `@rhing.jp` で行い、Protonで送信まで完結させたい場合は、Protonの有料プランが必要（独自ドメイン対応）
- メールアドレス表記を変える場合（お問い合わせ先を `rhing.official@gmail.com` から `info@rhing.jp` にする等）は、問い合わせフォームの送信先や特定商取引法の表記など、サイト内の連絡先も見直す
