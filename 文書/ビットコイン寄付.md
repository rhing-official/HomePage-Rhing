# ビットコイン寄付の受付（NOWPayments + SBI VCトレード）

`/donate` でビットコインによる寄付を受け付けるための方針・手順・進捗。

## 方針（2026-10-17 決定）

- 方式: 決済サービスのホスト型決済リンクを `/donate` のボタンに貼る（方式A）
- 決済サービス: **NOWPayments**（アカウント作成済み）
- 事業形態: 個人事業主
- 受取: ビットコインのみ。受け取ったら**円に換えず保有する**
- 受取先: **SBI VCトレードの口座**（すでにビットコインを管理している。自己管理型ウォレットではなく、取引所での保管）
  - 理由: 運用を一か所にまとめられる、年間取引報告書で税務の記録が楽、円への換金が同じ口座でできる
  - デメリット: 取引所の障害・停止の影響を受ける（SBI VCトレード自身も、倒産時に返還できない可能性がある旨を案内している）。入庫のたびに送付元の確認が入る可能性がある（後述）。件数が増えて負担になったら、自己管理型ウォレットへの切り替えを検討する
- 他の支払い方法（クレジット・デビット・PayPay）は準備中のまま。`/donate` は当面「ビットコインのみ受付中」にする

## SBI VCトレードの入庫ルール（公式ページの確認結果）

確認したページ: 「暗号資産の入出庫について」、ご利用ガイド「入庫」。

- 入庫手順: アプリの「入出金」→「入庫」で銘柄を選ぶとアドレスが表示される。トレーダーモードは「アカウント情報」→「暗号資産入庫」
- BTCのネットワークは「Bitcoin」のみ。未対応ネットワークで送ると回復できない。誤ったアドレスやネットワークへの送付は、原則返還されない
- 入出庫手数料は無料（ネットワーク手数料は送る側）
- ブロックチェーン上の処理後、登録メールに「入庫情報入力のお願い」が届き、アプリで入庫情報を入力する。トラベルルール等に基づく確認があり、審査完了後に口座へ反映される
- 大口の前に少額テスト送金が推奨されている。ウォレットアドレスは不特定多数へ公開しない
- 問い合わせ: 24時間のチャットボット、平日10:00〜17:00の有人チャット

**公式ページに記載がなく、確認が必要な点**

- 第三者のウォレットや決済事業者（今回の送付元は NOWPayments が管理するウォレット）からの入庫が可能か、条件や制限
- 入庫のたびに送付元情報の入力が必要か、反映までの時間（BTCの通常入庫）
- 入庫アドレスが固定か、変わるか、再利用してよいか
- 最低入庫数量
- ご利用ガイドは「ご自身で作成・管理しているウォレット」からの送付を前提にしている。NOWPayments経由の寄付がこれに当たるか

→ SBI VCトレードのサポート（チャット）に確認する。問い合わせ文の案:

> ビットコイン（BTC）の入庫について確認させてください。個人事業主として、暗号資産の決済サービス（NOWPayments）を使ってビットコインでの寄付を受け付ける予定で、受取先として貴社の入庫アドレスを指定したいと考えています。
> 1. 決済サービス事業者が管理するウォレットから貴社口座への入庫は可能でしょうか。可能な場合、条件や制限はありますか。
> 2. 入庫のたびに「入庫情報入力のお願い」への回答が必要でしょうか。反映までの時間の目安を教えてください。
> 3. 入庫用アドレスは固定でしょうか。複数回の入庫に同じアドレスを使い続けて問題ありませんか。
> 4. BTCの最低入庫数量はありますか。

## 注意

- アドレスは、全文をコピーして貼り、最初と最後の数文字を目で照合する。1文字違えば資金を失う
- 本番の前に、必ず少額でテスト送金する
- 受取先アドレス・APIキー・SMTPキーなどの秘密情報は、このリポジトリや日記に書かない（公開リポジトリ）
- 受領したビットコインは、受領時点の時価で円換算して収入の記録を残す（日時、取引ID、数量、円レート、円換算額）。区分や申告は税理士に確認する
- 寄付金控除の対象にはならない旨は、`/donate` のFAQに記載済み

## 設計の決定事項（2026-10-17）

- NOWPaymentsの最低決済額は約21USD（寄付ツールでは0.0002625BTC、円換算で約3,000円台、為替で変動）。500円・1,000円・3,000円の固定金額はビットコインでは払えないため、金額カードは廃止した
- `/donate` は「お支払い方法を選ぶ」形（`src/components/DonateMethods.tsx`）。ビットコインを選ぶと、最低額などの説明と「寄付ページへ進む」ボタン（上記リンク）が出る。クレジット・デビット・PayPay は「準備中」。他の方法が使えるようになったら、その方法を選んだときだけ小額の金額カードを出す想定
- NOWPaymentsの「Your API key」は秘密のキーの可能性がある。画面に写ったため、Settings → Payments → API keys で再発行を推奨した（再発行したかは未確認）
