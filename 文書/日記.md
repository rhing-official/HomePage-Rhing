### 詰まったところ
- ログインページが開いた瞬間に元のページへ戻されてしまうバグが発生。原因は`ready && user && redirectTo`で無条件にリダイレクトする`useEffect`が、既にログイン済みのユーザーにも反応してしまっていたこと。サインイン操作完了後の`.then()`でのみリダイレクトする`redirectIfSignedIn()`に変更して解消
- `ImagePicker`のプレビューURL生成で`useEffect`内`setState`がESLintの`react-hooks/set-state-in-effect`に抵触。`useMemo`でプレビューURLを算出し、`useEffect`はクリーンアップ（`URL.revokeObjectURL`）専用にする構成に変更して解消
- Firebase CLIのログインが`Failed to make request to https://auth.firebase.tools/attest`で失敗。原因はGNOMEのシステムプロキシ設定（`org.gnome.system.proxy` = `manual`、学校の`proxy.kasd.ac.jp:8080`を指していた）と、`~/.bashrc`内の`proxy_on`/`proxy_off`関数（`proxy_on`が呼ばれたまま`proxy_off`されていなかった）の2箇所が原因。両方解消してログイン成功
- Firebase Functions v2は`--only functions:createCheckoutSession`のように対象を絞っても、コードベース内の全関数が参照する`defineSecret`の値が揃っていないとデプロイ自体が失敗する（`STRIPE_WEBHOOK_SECRET`未設定の状態で`createCheckoutSession`単体デプロイがエラーに）。両方のシークレットを設定してから同時デプロイすることで解消
